## Congo Libs

Projet d'équipe : une bibliothèque en ligne pour retrouver livres, sujets de concours et sujets d'examens, puis accéder aux documents PDF.

Le backend comprend la recherche et les filtres par type de document, l'authentification web et mobile, des rôles d'administration et une documentation OpenAPI. Les PDF sont stockés sur Google Drive ; l'historique de téléchargement est associé aux utilisateurs.

**État :** backend au stade MVP fonctionnel, en développement. Le code n'est pas public.

**Technologies du projet :** Python, Django, Django REST Framework, SQLite / PostgreSQL, Google Drive API, Brevo et React.
